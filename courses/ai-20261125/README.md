# Training materials from the course AI course in Riga, 25-26 November 2026

## Scripts

-   `process-ai-20261125.sh`: Script to move the downloaded slides (that should be in the work
    area) to their final location in the staging area for LUMI-O and rename them.

-   `video-ai-20261125.sh`: Get the videos from the video processing directory on my local
    computer and put them in the right place for pushing to LUMI-O.

## How to process the files with slides

-   Download the course from the [Eduuni-workspaces site](https://tt.eduuni.fi/sites/csc-LUST_LO/Documents/Forms/AllItems.aspx?id=%2Fsites%2Fcsc%2DLUST%5FLO%2FDocuments%2FGetting%20started%20on%20AI%20workshop): 
    Select the training (2026-11 AI workshop) and click "Download".

    This will produce a file "OneDrive_<date and time>.zip

-   Go into the `ai-202611` subdirectory of the work subdirectory and unzip the file you just downloaded.

    This should create the subdirectory "2026-11 AI workshop"
